四、JSONL 交互设计

◀ 上一条 第 42 / 1,280 行 缩进： 下一条 ▶
4041424344…
▼ { 3 items }
  "id": 1042
  "name": "event_click"
  ▼ "payload": { 2 items }
    "x": 320
    "y": 480

核心交互

  • 打开 JSONL → 自动解析第一行，展示树结构
  • ◀ ▶ 按钮切换上一条/下一条，或键盘 ← →
  • 左侧行号列表，当前位置高亮，点击跳转
  • 文本视图显示当前行原始文本，可编辑
  • 全局搜索：搜索所有行中的 key/value，结果弹列表，点击跳转对应行

编辑边界

  • 编辑当前行后，重新序列化该行 → 写回原位置
  • 每行独立校验：某行 JSON 无效不影响其他行
  • 格式化只作用于当前行
  • 批量格式化：一键格式化全部行
  • 保存时完整写回文件，无效行保留原文 + 标记

六、技术选型

UI 框架

SwiftUI（窗口外壳 + 工具栏） + AppKit（NSOutlineView + NSTextView）

配色方案

硬编码深色：背景 #1e1e1e，文字 #d4d4d4，无切换逻辑

JSON 解析

JSONSerialization（Foundation），零三方依赖

JSONL 解析

逐行读取 → JSONSerialization 逐行解析 + 懒加载

文件关联

UTType + NSDocument，注册 .json/.jsonl/.ndjson

打包分发

Xcode Archive → DMG → 公证签名 → GitHub Release → V1 加 Homebrew Cask
