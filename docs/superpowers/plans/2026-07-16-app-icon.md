# DotJSON App Icon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 生成确认后的 DotJSON「点括号」图标，并用同一 1024×1024 母版等比例导出完整 macOS 图标资源。

**Architecture:** 使用内置图像生成能力创建唯一的高分辨率 PNG 母版，人工检查构图后，用 macOS `sips` 从母版等比例缩放出 iconset 的全部尺寸，再用 `iconutil` 生成应用实际消费的 `AppIcon.icns`。现有 Swift、Info.plist 与构建脚本继续使用 `AppIcon.icns`，不引入运行时依赖。

**Tech Stack:** OpenAI 内置图像生成、PNG、macOS `sips`、`iconutil`、Swift Package Manager

## Global Constraints

- 核心符号必须是白色 JSON 花括号 `{ }` 与中心青色圆点。
- 背景必须是深夜蓝到近墨黑的低对比度渐变，并在右上区域保留克制的青色柔光。
- 不得包含文字、水印、通知角标、文档纸张、树节点或外部背景场景。
- 所有输出尺寸必须由同一 1024×1024 母版严格等比例缩放，禁止按尺寸重新排版。
- 32px 下必须能辨认花括号与中心圆点，且不得粘连成无法识别的亮斑。
