# 工具栏分隔符收口设计

## 目标

消除 macOS 工具栏中，当前置编辑操作未显示时仍保留的孤立分隔符及其留白。

## 范围

- 调整 `ToolbarView` 的工具栏分组结构。
- 将编辑操作（格式化、压缩、缩进）与文件操作（清空、粘贴、复制、导出）分为独立的原生工具栏组。
- 不改动各按钮的行为、快捷键、提示文案或搜索区域。

## 行为

macOS 隐藏或自定义编辑操作组时，文件操作组不再携带前置分隔符，会从自身的首个按钮自然开始显示；用户仍可在系统工具栏自定义中独立控制两个组。

## 验证

- 编译 macOS Swift Package。
- 运行现有测试，确认工具栏代码调整不影响编辑与剪贴板行为。
