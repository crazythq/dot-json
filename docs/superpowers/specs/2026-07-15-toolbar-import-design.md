# 工具栏导入按钮设计

## 目标

在 macOS 客户端工具栏中提供一个“导入”入口，让用户可以从系统文件选择框加载一个 JSON 文件。

## 范围

- 在工具栏的文件操作分组中、清空按钮之前增加“导入”按钮。
- 按钮使用 `square.and.arrow.down` 图标，提示文本为“导入 JSON 文件”。
- 点击后显示 `NSOpenPanel`，只允许选择一个 `.json` 文件。
- 选择文件后复用 `EditorViewModel.loadDocument(from:)`：加载文本、更新当前文件 URL 和最近文件列表。
- 加载失败时调用 `reportFileError(_:)`，沿用现有编辑器错误反馈。

## 非目标

- 不支持一次导入多个文件。
- 不支持 JSON 以外的文件类型。
- 不改变菜单“打开”、拖放或 Finder/Dock 打开文件的行为。
- 不新增另一套文件解析或加载状态。

## 实现边界

导入面板逻辑保留在 `ToolbarView`，与现有导出面板的位置一致。文件读取、扩展名校验和错误状态统一委托给 `EditorViewModel`，避免工具栏复制业务逻辑。

## 验证

- 新增源码级工具栏测试，确认导入按钮及其触发方法存在。
- 运行完整 Swift 测试套件，确保既有工具栏、文件加载和最近文件行为不回归。
