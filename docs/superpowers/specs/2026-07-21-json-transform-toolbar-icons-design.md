# JSON 转换工具栏图标设计

## 目标

优化 macOS 工具栏中“格式化”和“压缩”两个图标，使用户无需依赖文字也能区分两种 JSON 转换结果。

## 设计

- “格式化”图标使用一对花括号包围三条错落的横线，表示带缩进的多行 JSON。
- “压缩”图标使用一对花括号包围一条横线，表示压缩后的单行 JSON。
- 两个图标共享相同的花括号轮廓、线宽和画布尺寸，形成明确的一组操作。
- 图标使用 SwiftUI 矢量路径绘制，并继承当前前景色，以适配深色、浅色和 Retina 显示。
- 保持现有按钮标题、悬浮提示、点击行为、尺寸和工具栏布局不变。

## 代码边界

- 在 `mac/Sources/DotJSON/Views/ToolbarView.swift` 中增加私有的 JSON 转换图标类型。
- 仅将“格式化”和“压缩”按钮的现有 SF Symbols 替换为新的矢量图标。
- 不修改格式化、压缩逻辑，不调整其他工具栏按钮或分组。

## 验收标准

- “格式化”显示花括号内多行结构，“压缩”显示花括号内单行结构。
- 两个按钮仍分别调用当前活动文档的 `format()` 和 `minify()`。
- 图标在深色和浅色工具栏中均清晰可见，尺寸与相邻原生图标协调。
- 工具栏结构测试和完整 Swift 测试通过。
- 在真实 macOS 应用窗口中检查图标的辨识度、对齐和缩放效果。

## 测试策略

先增加一个会失败的结构性回归测试，约束两个按钮使用对应的自定义图标类型；再实现最小矢量图标代码使测试通过。随后运行工具栏定向测试和完整测试，并启动应用进行截图验收。
