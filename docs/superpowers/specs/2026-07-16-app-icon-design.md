# DotJSON macOS 应用图标设计

## 目标

为 DotJSON 设计一枚适用于 macOS Dock、Finder 与应用切换器的应用图标。图标需要直接体现 JSON 工具属性，同时在 32px 小尺寸下保持清晰辨识，并改善现有纯深色方块在 Dock 中难以识别的问题。

## 最终方向

采用「点括号」方案：白色 JSON 花括号 `{ }` 与中心青色圆点组合。

- 花括号代表 JSON 数据格式。
- 中心圆点呼应产品名中的 `Dot`，形成 DotJSON 专属符号。
- 不加入文字、文档纸张、树节点或其他辅助元素，避免小尺寸信息过载。

## 视觉规范

### 外形

- 使用符合 macOS 应用图标习惯的圆角方形轮廓。
- 图标主体保留安全边距，避免在 Dock 中显得过满。
- 内侧使用一条低对比度高光描边，增强边界，但不形成明显双层边框。

### 配色

- 背景：从左侧近墨黑深夜蓝到右侧克制深蓝的水平线性渐变。
- 背景不得包含局部高光、径向光斑、垂直明暗变化或右上角青色柔光。
- 花括号：接近白色的冷白色。
- 中心圆点：明亮青色，并带轻微同色光晕。
- 整体保持冷静、专业的开发者工具气质；不使用高饱和大面积紫色或暖色。

### 质感

- 采用现代 macOS 图标风格，允许轻微立体感、内侧高光和柔和投影。
- 不使用照片质感、复杂纹理、玻璃拟态、强烈金属反射或厚重 3D 元素。
- 不包含文字、水印、通知角标或外部背景场景。

## 构图与缩放

- 以单一正方形母版作为唯一视觉源。
- 花括号、圆点、圆角、描边、渐变与光晕必须随整张母版严格等比例缩放。
- 不为 128px、48px 或 32px 预览单独改变字号、间距或圆点尺寸。
- 输出图标集时，各尺寸从同一高分辨率母版缩放生成，禁止按尺寸重新排版。
- 32px 下仍需能辨认花括号和中心圆点，且两者不得粘连成无法识别的亮斑。

## 交付物

- 一张 1024×1024 PNG 母版。
- 一张与母版一致、供未来 uTools 插件复用的 `utools/icon.png`。
- macOS `AppIcon.iconset` 所需的 16、32、128、256、512px 及对应 `@2x` PNG。
- 由该 iconset 生成的 `AppIcon.icns`。
- 所有尺寸均由同一母版等比例缩放，并在生成后进行图像尺寸和视觉抽查。

## 验收标准

- 在浅色与深色桌面背景中，图标轮廓均清楚。
- 128px、48px 和 32px 预览的所有元素与母版保持相同比例。
- 32px 下可以识别 `{ }` 与中心圆点。
- 图标中不存在额外文本、通知角标、裁切、拉伸或不一致的局部缩放。
- 生成的 PNG 尺寸完整，`AppIcon.icns` 可被 macOS 应用构建流程正常使用。
