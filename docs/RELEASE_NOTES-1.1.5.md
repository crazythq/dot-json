# DotJSON 1.1.5

## macOS app

- **Toolbar** — removed the main-window indent picker; Format, Minify, Convert, Clear, Paste, Copy, Import, and Export now share the same icon-above-label layout and sizing. On narrow windows, captions hide first; further overflow uses the system toolbar menu.
- **Indent** — the current tab’s indent cannot be changed from the toolbar for now. **Settings → Default Indent** still applies to newly created documents; existing tabs keep their stored indent.
