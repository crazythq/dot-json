# DotJSON — uTools 插件

> 计划中的 uTools 插件版本，使用 uTools 插件 API 实现 JSON 格式化/浏览。

## 技术栈（预期）
- HTML/CSS/JS (uTools 插件标准)
- 复用 DotJSONCore 的设计规范（树模型、格式化 API）
- 独立实现（JavaScript），不依赖 Swift

## 状态
🟡 计划中 — Mac App MVP 完成后再启动。

- `icon.png`：预留给未来 uTools 插件使用的 1024×1024 RGBA 图标源。
